# Задача: описание скриптов в блоке aside

Документ описывает логику работы блока боковой панели (aside), назначение каждого виджета и поведение скриптов.

---

## 1. Общая структура aside

Блок **aside** (класс `.aside`) — боковая колонка справа от основного контента (на десктопе) или под ним (на узких экранах). Внутри:

- три виджета контента: «В ожидании», «Популярные статьи», «Комментарии»;
- подвал панели (`.aside-footer`) с навигацией и копирайтом.

Скрипт, относящийся к aside, в **scripts/main.js**: сохраняет и восстанавливает состояние **сворачиваемых** виджетов в `localStorage`.

---

## 2. Виджет «В ожидании» (widget--awaiting)

**Назначение:** показывать список ожидаемых событий (премьеры, релизы и т.п.) — заголовок, краткое описание, дата/время.

**Разметка:**
- Контейнер: `<div class="widget widget--awaiting widget--no-collapse">` (не `<details>`).
- Заголовок: `.widget-summary` с `<h4 id="awaiting-title">В ожидании</h4>`.
- Контент: `.widget-content` → список `.awaiting-list` с элементами `.awaiting-item` (`.awaiting-title`, `.awaiting-desc`, `.awaiting-date` с `datetime`).

**Поведение:**
- Всегда развёрнут, свёртку не поддерживает (класс `widget--no-collapse`).
- Скрипт aside с этим виджетом ничего не делает (обрабатываются только элементы `<details class="widget ...">`).
- Ожидаемое поведение: только отображение статического/динамического списка; клики по пунктам при необходимости обрабатываются отдельно (например, переход на страницу события).

**Где используется:** index.html, fullnews.html (одинаковая структура).

---

## 3. Виджет «Популярные статьи» (widget--popular-articles)

**Назначение:** список статей, отсортированных по популярности (рейтинг/просмотры), с кратким описанием и метой (лайки, просмотры). По клику — переход на страницу статьи.

**Разметка:**
- Контейнер: `<details class="widget widget--popular-articles" open aria-labelledby="popular-articles-title">`.
- Заголовок: `<summary class="widget-summary">` с заголовком и иконкой (стрелка вниз).
- Контент: `.widget-content` → список `.popular-articles` с `.article-item`.
- Каждый пункт: ссылка `.article-link` с:
  - `.article-rank` — место в рейтинге (1, 2, 3…);
  - `.article-title` — заголовок статьи;
  - `.up` — «поднялось на N позиций» (опционально);
  - `.article-main` — выдержка (`.article-excerpt`) и мета (лайки/просмотры в `.article-meta`).

**Поведение:**
- Виджет можно **свернуть/развернуть** (стандартное поведение `<details>` по клику на `<summary>`).
- Скрипт при загрузке читает из `localStorage` (ключ `niwado-aside-widgets-open`) состояние по ключу `popular-articles` и выставляет атрибут `open` у `<details>` (развёрнут/свёрнут).
- При каждом переключении (событие `toggle`) скрипт сохраняет текущее состояние всех сворачиваемых виджетов aside в `localStorage`.
- Ожидаемое поведение: список ведёт на страницы статей; сворачивание/разворачивание блока запоминается между визитами.

**Где используется:** index.html, fullnews.html.

---

## 4. Виджет «Комментарии» (widget--popular-comments)

**Назначение:** список последних или популярных комментариев — превью текста, автор, время, рейтинг. По клику — переход к комментарию (например, на страницу записи с якорем).

**Разметка:**
- Контейнер: `<details class="widget widget--popular-comments" open>`.
- Заголовок: `<summary class="widget-summary">` с текстом «Комментарии» и иконкой.
- Контент: `.widget-content` → список `.popular` с `.popular-item`.
- Каждый пункт: `.popular-main` с:
  - `.popular-body` — ссылка `.popular-link` (текст комментария) и рейтинг `.popular-rating` (иконка + `.popular-rating-value`);
  - `.popular-head` — автор (`.popular-author`, при необходимости со Schema.org) и время (`.popular-meta-time` с `datetime`).

**Поведение:**
- Аналогично «Популярным статьям»: виджет можно **свернуть/развернуть** через `<details>`.
- Скрипт сохраняет и восстанавливает состояние по ключу `popular-comments` в `localStorage`.
- Ожидаемое поведение: клик по комментарию ведёт на страницу с этим комментарием; свёрнутое/развёрнутое состояние блока запоминается.

**Где используется:** index.html, fullnews.html.

---

## 5. Скрипт состояния виджетов aside (main.js)

**Назначение:** запоминать, какие из сворачиваемых виджетов в aside развёрнуты, а какие свёрнуты, и восстанавливать это при следующем заходе на сайт.

**Логика:**

1. **Ключ в localStorage:** `niwado-aside-widgets-open`. Значение — JSON-объект вида `{ "popular-articles": true, "popular-comments": false }`, где ключ — идентификатор виджета, значение — открыт (`true`) или закрыт (`false`).

2. **Идентификация виджета:** из класса элемента берётся подстрока после `widget--` (например, `widget--popular-articles` → ключ `popular-articles`). Реализовано в `getWidgetKey(el)` через регулярное выражение по `className`. Виджеты без такого класса (или не `<details>`) в состояние не попадают.

3. **Восстановление при загрузке:**
   - Найти контейнер `.aside`.
   - Прочитать объект из `localStorage` (`readAsideWidgetsState()`).
   - Для каждого элемента с классом `.widget` (внутри aside) получить ключ `getWidgetKey(details)`. Если в сохранённом состоянии есть значение для этого ключа — выставить или снять атрибут `open` у элемента (для `<details>` это даёт развёрнутое/свёрнутое состояние).

4. **Сохранение при переключении:**
   - На каждый виджет (`.widget`) внутри aside повешен обработчик события `toggle`.
   - При срабатывании вызывается `saveAsideWidgetsState(aside)`: обходим все `.widget`, для каждого с имеющимся ключом записываем в объект `details.hasAttribute('open')`, объект сериализуется в JSON и сохраняется в `localStorage` под ключом `niwado-aside-widgets-open`.

**Важно:**
- Обрабатываются только элементы, которые являются `<details>` и имеют класс вида `widget--*`. Виджет «В ожидании» — `<div>`, не участвует в сохранении состояния.
- При ошибке парсинга JSON из `localStorage` используется пустой объект; при ошибке записи — тихо игнорируется.

**Ожидаемое поведение в итоге:**
- Пользователь сворачивает/разворачивает «Популярные статьи» или «Комментарии» → состояние сохраняется.
- После перезагрузки страницы или следующего визита блоки открыты/закрыты в соответствии с последним выбором.

---

## 6. Подвал aside (aside-footer)

**Назначение:** дополнительная навигация (О проекте, Правила, Реклама, Помощь) и копирайт с названием проекта.

**Разметка:** `<footer class="aside-footer">`, внутри — `<nav>` с ссылками и блок с копирайтом. Скриптов для footer в aside нет; поведение — только переход по ссылкам.

---

## 7. Краткая сводка по скриптам и виджетам

| Блок в aside              | Элемент        | Сворачивание      | Участвует в скрипте (localStorage) |
|---------------------------|----------------|-------------------|-------------------------------------|
| В ожидании                | div            | Нет (всегда открыт) | Нет                                 |
| Популярные статьи         | details        | Да (summary)      | Да, ключ `popular-articles`         |
| Комментарии               | details        | Да (summary)      | Да, ключ `popular-comments`         |
| Подвал (навигация, копирайт) | footer      | —                 | Нет                                 |

Единственный скрипт, относящийся к aside, — сохранение и восстановление состояния открыто/закрыто для виджетов на `<details>` с классом `widget--*`.
